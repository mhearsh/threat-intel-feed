# Security policy
This repository publishes threat-intelligence data only.
- **False positives** (a benign IP, domain or URL listed): open a "False positive" issue.
- **Sensitive reports** (e.g. a victim's identifying data was included by mistake): use GitHub's private vulnerability reporting (Security → Report a vulnerability). Do not open a public issue.
We aim to respond within 24 hours, and confirmed removals take effect on the next run (≤ 2h).
